# mObywatel Web

Strona internetowa mObywatela - społeczny projekt odtwarzający interfejs oficjalnej aplikacji mobilnej mObywatel.

## 🚀 Funkcjonalności

- ✅ Responsywny design na wszystkie urządzenia
- ✅ Nowoczesny interfejs nawiązujący do aplikacji mobilnej
- ✅ Informacje o obsługiwanych dokumentach
- ✅ Sekcja bezpieczeństwa
- ✅ Szybki czas ładowania
- ✅ Optymalizacja SEO

## 🛠️ Technologia

- **Next.js 14** - Framework React
- **TypeScript** - Typowanie
- **Tailwind CSS** - Stylowanie
- **Lucide React** - Ikony

## 📦 Instalacja

```bash
# Clone the repository
git clone https://github.com/bartoszgaudy706-jpg/mobywatel-web.git
cd mobywatel-web

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## 🔨 Budowanie

```bash
npm run build
npm run start
```
